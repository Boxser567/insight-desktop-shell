# 达人营销 - 整合类技能 🌱

专业的达人营销整合类全案策划技能，输出完整的 **6 大模块**方案：**洞察→人群分析→社媒传播主题→核心玩法→传播部分→传播效果**。

## 功能特点

- ✅ 支持抖音/小红书/B 站/快手等多平台
- ✅ 完整的 6 大模块输出框架（整合类）
- ✅ 遵循 MKT 系列营销规范（MKT-001~014）
- ✅ 整合 DSH web_search、灵感库 API、media-generator 等技能
- ✅ 可执行的种草方案，包含预算划分和效果预估
- ✅ 避免低级错误检查清单（web_search、Media Generator 等）

## 触发词

```
达人种草 | 种草方案 | KOL 投放 | KOC 种草 | 达人矩阵
媒介策略 | 投流规划 | 种草全案 | 小红书投放 | 抖音达人
达人营销整合 | 整合营销方案
```

## 6 大模块输出框架

```
一、洞察 → 二、人群分析 → 三、社媒传播主题 → 
四、核心玩法 → 五、传播部分 → 六、传播效果
```

### 模块一：洞察
- Brief 解读（营销目标及任务）
- 行业洞察/场景洞察（行业趋势总结）
- 竞品社媒平台投放分析（卖点/内容/投放数据/达人类型量级/不足与优势）
- 本品社媒平台投放分析（卖点/内容/投放数据/达人类型量级/不足与优势）
- 总结：产品卖点、本品投放机会点、本品与竞品差异点

### 模块二：人群分析
- 人群画像描述（年龄、兴趣、地域）
- 用户消费行为习惯
- 用户社媒偏好
- 总结：用户喜欢的内容及调性

### 模块三：社媒传播主题
- Core Idea
- 传播主题/Slogan（3-5 个供选择）⏸️ **需用户确认**
- 传播调性/人设

### 模块四：核心玩法
- 视觉创意（KV、视觉符号等）
- 互动机制（用户互动玩法设计）
- 创意落地（具体执行形式）

### 模块五：传播部分
- 话题方向（根据传播主题和创意定制不同的传播方向）
- 媒介策略（不同平台匹配不同传播方向内容）
- 投放矩阵（根据不同平台，指定不同量级达人进行投放）
- 传播节奏（定制不同阶段不同内容的传播图）

### 模块六：传播效果
- 预算划分及互动、曝光效果预估

## ⚠️ 避免低级错误

### 联网检索（DSH web_search）
- 统一通过 DSH 官方 `web_search` 工具检索，无需外部 API Key
- 禁止直接说"没有数据"——用 `web_search` 检索最新报告

### Media Generator 调用
- 所有业务参数（prompt、image_params 等）**必须**嵌套在 `data` 对象内
- 错误格式：`prompt` 放在根级别
- 正确格式：`data: { prompt: "..." }`

### 数据引用
- 每个数据点必须标注引用来源 `[1]` `[2]`
- 引用必须包含可访问的 URL 链接
- 所有数据基于 API 真实返回，禁止编造
