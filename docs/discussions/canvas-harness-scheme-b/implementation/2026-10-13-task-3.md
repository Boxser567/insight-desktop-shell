## 实际入参、出参与调用链

```ts
canvas_create({name?:string})
canvas_get({canvasId:string,view?:'summary'|'nodes',nodeIds?:string[],refresh?:boolean})
canvas_node_edit({canvasId:string,expectedVersion:string,action:'add',node:NodeDraft})
```

工具输出仍为JSON字符串，由原text renderer显示，不要求用户填写内部技术身份。

- create：name默认“新画布”，trim后1–100字符。Host复用现有saveOrUpdate，固定空图nodes/edges、temp:false、canvasType:0、version:comfyui。得到合法ID后用bridge.ensureContext(read)准备服务；返回created、ID/address/name、真实版本或null、runtime:ready/not_ready。准备失败仍保留已创建ID，不再创建。
- get summary：默认原Host fetchCanvas，不依赖Agent/Client；保持canvasId/name/nodeCount/nodes/address形态，最多20条摘要。title优先原生data.title，兼容旧title；summary不接收nodeIds/refresh。
- get nodes：当前对话Agent身份 → ensureContext(read,refresh?) → dispatch(canvas.read)。nodeIds可省略，取得空图版本或前20个节点及总数；提供时1–20个唯一ID。refresh:true才权威重载；结果保留confirmed/unconfirmed、version、missingNodeIds和truncatedFields，source:plugin-service。
- add：当前Agent身份 → parseBridgeOperation(node.add) → ensureContext(edit) → dispatch。expectedVersion不推算、不自动替换；原生方法负责默认模型/参数、命名、容量、编辑保护和队列内版本复查。保存成功返回saved、实际节点ID、版本；不调用invoke。

`String(exec.agent.id)`对应会话ID；内部requestId由sessionId/callId/toolName做SHA-256，再使用不同的prepare/read/add后缀。模型不能指定会话、连接、context或requestId。调用复用同一个Host bridge，没有额外HTTP业务dispatch或iframe命令层。

## 去重、失败与Review修复

- 创建按真实调用身份缓存规范化名称和结果，含并发/created/unknown/明确拒绝；相同调用不同名称拒绝。上限1024记录、8在途，达到上限拒绝，不驱逐旧写回执以放行新创建。作用域为插件进程，不承诺跨重启exactly-once。
- 传输丢失、5xx、408、畸形成功响应、缺ID或不安全number ID：create_unknown/never_auto，单次发送。明确4xx/业务拒绝与发出前失败返回rejected/effect:none。创建ID已确认、服务暂不可用时是created/runtime:not_ready；后续操作同ID。
- 节点去重复用任务2原请求缓存；save未知保留原status/version/affectedNodeIds，工具输出的retry提示统一never_auto，不修改原回执对象或UI。该差异由真实原生集成先复现后修复。
- dispatch尝试后出现未知异常，工具保守返回submission_unknown，不能伪报effect:none；通用异常文案受控，不回显Token或原始传输错误。
- 原生登录协议中的USER_SESSION_EXPIRED、USER_NOT_LOGIN和-1业务码即便HTTP200，也明确返回AUTH_REQUIRED。新增回归先复现误分类，再修复；不自动重试创建。
- canvasId在BigInt解析前限制19字符；创建响应只接受合法字符串或安全整数，避免数字精度丢失。

必要开发SDK由dsh-tools0.1.6-alpha.2→0.2.1-alpha.1、Cordis4.0.4→4.0.5-alpha.1；后者是当前tools声明的必要peer。lockfile联动其依赖，未升级React/Web依赖。旧Client开发包可产生peer警告；实际Core类型、安装及注册通过。插件运行peer要求tools0.2.1-alpha.1，不宣称新工具兼容旧Core。
