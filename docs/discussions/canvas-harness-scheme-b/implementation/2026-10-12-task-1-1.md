## 已落实的规则与复用

- title 复用 validateNodeTitle；text 仅写 text 节点 data.value；prompt 写 params.prompt。对象、未知字段、模型 / 模式切换及 text/audio 技术 params 修改被拒绝。
- image/video 复用 buildMediaNodeParamState、isMediaParamValueUnavailable、validateMediaNodesForRun 与原生权限方法；校验合并后的组合，不自动改掉另一项来通过级联。
- gen_count 从 timeParam 取得选项，严格保留原生选项值类型。合法数字串仅在配置明确提供该字符串时可用，计数返回正安全整数；缺配置、禁用模型、缺数量或非法组合返回 null。
- 构造节点复用 util.createNode 与 applyEmptyMediaNodeDimensions：UUID、默认参数、标题、taskInfo 和空媒体尺寸来自原业务，不写死模型。
- 详情保留原始入边顺序及 handles，包括尚无素材的来源节点；原 getSourceMap 只返回有内容的输入且不能完整表达重复边，因此详情从 Store 原 edges 映射。后续生成继续使用原生输入处理。
- 详情不返回内部 taskInfo 等对象；产物只读取已有 URL，去重且最多 20 条，排除登录凭证；不下载。文本、提示词和标题超限报告 truncatedFields，不修改 Store 原数据；无法缩减的过大详情明确拒绝。
- v2 解析拒绝额外 / 条件不符的字段、非法身份、非有限数值与超大消息。canvasId 保留正 Long 字符串；节点 ID 1–100 字符、路由 ID 1–200 字符、version 1–100 字符；字符串身份不使用 Number 转换。read/delete IDs 按原顺序去重，最多 20 个。

数量函数比原草稿多接收 state，因为仅看 node 无法证明当前模型、选项和权限合法。该签名已回写实施计划。技术 params 当前只开放原生选项可证明合法的标量字段；没有可验证选项的自由输入 / 高级对象字段继续拒绝。
