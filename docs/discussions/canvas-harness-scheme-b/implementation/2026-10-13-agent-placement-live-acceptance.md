# alpha.11坐标修复：安装与手动验收

当前代码/自动回归/包已完成；本轮未自动安装到真实账号。请先通过原生入口导入alpha.11，再用新会话验收。无需生成图片、视频或修改代码。

## 1. 安装

1. 因赛AI菜单“插件”→“导入本地插件”，选择[alpha.11包](../../../../../desktop-canvas-plugin/insight-ai-desktop-canvas-plugin-0.3.0-alpha.11.tgz)。
2. 等待Harness恢复，核对插件为0.3.0-alpha.11且启用。如果界面未加载新工具描述，空闲时使用“Harness→重启Harness”。不使用alpha.10替代此次验收。
3. 新建“坐标修复验收”专用聊天，关闭画布面板，准备一张图片附件。可用[测试PNG](evidence/task-4-test-image.png)，也可用耳机图；尽量再备一张宽图/长图补测尺寸。

包SHA256：`d82da6fc0df3f1791063a437eef7ad6fb95a05526070906a23e9b6ad1846b1ec`。

## 2. 默认自动放置

发：

> 创建一个叫“坐标修复验收”的空画布。依次新增两个文本节点：“文案A”，正文“首屏卖点”；“文案B”，正文“产品说明”。都使用默认自动放置，只保存、不生成、不打开画布、不修改代码。保存后从后端重新读取，告诉我画布ID、每个节点ID、position、size、parentId和版本。

通过条件：

- 工具实际为canvas_create、两次canvas_node_edit(action:add)，默认不传placement或mode:auto，不再传裸node.position。
- 每次saved后采用可信新版本；canvas_get(view:nodes,refresh:true)返回read/confirmed。
- 第一节点正常0,0；第二节点x在第一节点右边留出120间距，不能同落0,0。
- 两个顶层parentId均null。记录画布ID=C、文案A节点ID=A、文案B节点ID=B。

附图片，再发：

> 将本条消息附上的图片作为素材节点导入画布【C】，标题“耳机原图”，使用默认自动放置。只上传保存、不生成、不打开画布。完成后从后端重新读取三个节点，报告坐标、显示尺寸、版本和资产登记状态。

通过条件：素材节点saved、登记registered；图片不落原点、不移动A/B；其位置在已有占用右侧。size是显示尺寸，不是原文件像素。坐标和素材URL经重载一致。

此时手动打开C，确认两个文本与图片没有默认遮挡。对比坐标；原生UI显示同内容。截图后可以关闭面板继续。

## 3. 精确坐标

发：

> 在画布【C】新增文本节点“精确坐标”，正文“位置验证”。明确使用精确画布坐标x=-600、y=0，只保存，不生成。不要自动调整这个坐标。保存后从后端重新读取，报告节点ID与position。

预期：canvas_node_edit内node.placement为 `{mode:'absolute',position:{x:-600,y:0}}`，不是裸position；saved，重载position原样，旧节点位置不变。

可选验证0,0：明确要求另一个测试节点以absolute放到0,0。它可能遮挡“文案A”，这是用户精确放置的预期，不算自动放置失败；无需为了测试默认路径主动制造这种遮挡。

## 4. 沿已有节点延展

发：

> 只在画布【C】的节点【A】右侧延展一个新文本节点，标题“邻近延展”，正文“沿原节点继续”。使用锚点延展放置，不要搬到整张画布最末尾，不创建连线、不生成。保存后重新读取新节点和A的坐标与尺寸。

预期：node.placement为 `{mode:'after',anchorNodeId:A}`；新节点x=A世界x+A显示width+120，y与A对齐。新节点不被其他远处内容推走；所有旧节点不动；不产生边。

它可能与“文案B”同位置，这是本轮允许的邻近延展规则，不要求全图消除重叠；用坐标和mode判定，不将这种情况误认为默认auto失效。模型不能说已创建真实连线。

## 5. 原生UI与持久化

- 手动移动一个旧节点并按原生方式保存；随后让Agent默认新增一个不同标题的文本，核对旧节点保持用户位置。
- 关闭画布后让Agent权威重载，检查同节点ID/坐标/正文；再打开原生UI核对。
- 原生UI手工新增、复制、解组、排版继续按旧行为工作，不会被Agent默认自动放置规则强制改写。已有复制/解组的画布，应能让Agent读取其节点详情，顶层parentId为null。
- 可补测宽图/长图导入后追加文本，确认位置参考实际显示宽度；若尺寸加载失败，记录返回size与UI表现，不声称永远无重叠。

## 结果与停止条件

看实际轨迹与saved/read回执，不只看Agent“成功”。Network不作为前置条件。

- 若仍见裸position：确认新包/新会话，保留工具结果；正确工具会INVALID_ARGUMENT提示placement，不应静默写原点。
- 若after缺失锚点：NODE_NOT_FOUND，不新增节点、不换ID乱猜；素材导入前上传可能已发生，节点保存与上传分开记录。
- VERSION_CONFLICT / EDITOR_BUSY：核对版本或结束编辑，不自动强写。
- submission_unknown/upload_unknown：停止自动重试，记录原调用与ID，先核对当前事实。
