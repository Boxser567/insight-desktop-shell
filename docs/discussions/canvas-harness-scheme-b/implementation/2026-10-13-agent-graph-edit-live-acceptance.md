# alpha.12 图编辑真实账号手测

目标：通过 Agent 对话创建真实有连接关系的业务图，修改/删除节点，查询并保存合法图生图配置；随后打开画布核对原生 UI 和重载结果。此轮仅保存，产物节点应为空；生成、抠图执行、模板和 Skill 继续另行推进。

最新逐条执行入口：[P01–P10可复制Prompt](2026-10-13-alpha12-copyable-prompts.md)。它细化了下方G01–G06，排序使用两个独立图片节点验证同类素材顺序，明确generation字段仅代表计划数量；建议此次账号手测采用P01–P10。

## 准备

1. 在 Shell 插件管理中导入 `desktop-canvas-plugin/insight-ai-desktop-canvas-plugin-0.3.0-alpha.12.tgz`，确认当前启用版本为 alpha.12；必要时按客户端提示重启。
2. 新建对话，确认实际加载七工具：canvas_create/get/node_edit/assets/asset_import/edges/models。旧对话或旧安装包仍可能展示旧能力描述，不能以旧 README 判断 alpha.12。
3. 使用新测试画布和一张商品图；保留已验收的103161/103165。以下每步记下真实画布ID、节点ID、边ID、保存版本、工具回执和界面截图。

插件包的绝对路径：`/Users/boxser.shi/Documents/harness/desktop-canvas-plugin/insight-ai-desktop-canvas-plugin-0.3.0-alpha.12.tgz`。本轮自动测试不安装或修改当前真实账号。

## G01 创建与导入（附耳机图）

```text
创建一个“Agent图编辑验收”画布，创建一个“头部文案”文本节点，正文为“轻巧随行，听见更多”。把我附上的耳机图导入为“耳机原图”图片素材节点，创建一个“头部卖点图”空图片生成节点。只编辑和保存，保持画布未打开，不执行生成。完成后列出画布ID、三个节点ID、最新confirmed保存版本。
```

验收：真实create/saved回执；图片原图outputs包含可访问素材URL，contentType为upload，generation为空；生成节点outputs为空。自动位置无缺省叠放，上传图仍使用原生尺寸。

## G02 建立真实业务连线

```text
读取刚才画布的真实图结构，将“头部文案”连接到“头部卖点图”的文本输入，将“耳机原图”连接到该节点的图片输入。复用原生端口并保存。列出两条真实边ID、source/target/handles和最新版本。
```

验收：canvas_get(view:graph)返回两条边；源分别为文本节点和上传图片，目标相同；边有真实ID与合法handles。原图的outputs是URL，节点inputs里的edgeId才是关联边，两者不能混用。默认文生图模式接入图片时可能出现兼容性warnings，saved仍表示图已保存。

## G03 查询当前模型并配置

```text
查询当前账号可用图片模式和模型，选择支持参考图片的图生图模式，给“头部卖点图”配置一个当前可用模型与合法的方图参数，gen_count为1。使用返回的真实value，保存后再读节点详情。只配置，不生成。报告最终modelType、model、参数选项和保存版本。
```

验收：先canvas_models再configure，模型值取当前账号目录；不固定gpt/gemini等模型。若账号没有图生图模型，明确记录CONFIGURATION_ERROR或目录为空，不声称完成。有模型时：params合法，原图仍upload来源、URL不改、生成节点仍无产物、空节点尺寸符合所选画幅。目录paramHints按默认父参数组合；配置后的实时choices看canvas_get(view:nodes)。

## G04 修改与素材保护

```text
将“头部文案”的正文改成“通勤轻负担，音乐随身听”，将“耳机原图”标题改成“耳机参考实拍”，保留图片本身。保存并返回版本；再次读取两个节点核对。
```

验收：正文和标题更新；上传来源URL、实际尺寸、contentType保持。可另外让Agent尝试配置上传原图的生成参数，以实际工具回执UNSUPPORTED_NODE为准；它不应把原图改成生成节点。

## G05 改接、输入排序与删除

1. 附第二张参考图，让Agent导入为“备用参考图”，使用reconnect把原图→生成节点那条边的来源改为备用图。
2. 让Agent读取该目标完整入边集合，并按“图片在前、文本在后”的顺序保存reorder。
3. 让Agent删除备用图；检查删除回执包含该图片节点ID及关联边ID，下游图片生成节点仍在。
4. 让Agent删除临时文本节点或一条测试连线，其他节点和其他目标的输入次序不受影响。

验收：reconnect边ID不变；reorder按完整目标集合执行，不调整无关边槽位；delete复用原生关联边与空组清理；删除唯一参考图后，仍保留的图生图节点应收到缺图片输入的warnings。每次写入使用最新confirmed版本。

## G06 打开、原生编辑和权威重载

1. 首次打开测试画布，核对真实连线、文本、图片原图、空产物节点、模型参数及画幅。
2. 在原生UI编辑文案并等待保存；让Agent读取更新结果。
3. 在UI仍输入草稿或拖动节点时让Agent修改，检查实际工具返回EDITOR_BUSY，而不是覆盖草稿。LLM若等待后再调用，未触发该保护路径，不能据此判定失败。
4. 关闭画布视图，让Agent用canvas_get(view:graph, refresh:true)权威重载，再读节点详情；核对保存版本及边/节点ID。

验收：没有因本轮编辑提交模型执行请求；关闭视图后Agent仍可读取/编辑，所有结果持久化；原生添加、连接、拖动、保存仍按原有行为。重载若提示当前编辑/运行未结束，应等待安全重载，不强行切换上下文。
