命令与事件

API提交动作，SSE归并执行事实。

◆ 执行路径在提交前决定
▲ 完整自动交付的必要条件
终态通知必须能取得真实产物，或后续保存通知可驱动读取。仅发success而没有可取结果，不能构成完整自动交付。
SSE的id / retry不自动代表历史回放。断线重连一次校准；心跳不触发任务查询。
展开既有API的职责
saveOrUpdate：创建 / 保存画布
get：准备、通知取结果或恢复时读事实
partialUpdate：节点patch，边集在最新图上重建
v2/workflow/invoke：精确区域或单节点生成
v2/workflow/interrupt：请求停止已知任务
listNodeSetting / listModelNodeSetting：模式、参数与权限
sts/token → OSS → upload/asset：上传并关联媒体

Host保存Run和逻辑映射；后端仍保存合法基础图与媒体。

模板作者的十步手册
  1. 写主产物和可选素材。
  2. 写商品用途与动作配方。
  3. 写用户必需、默认和派生输入。
  4. 写可变创意和保护要求。
  5. 用逻辑键与有序角色连接受支持操作。
  6. 分清远端DAG、本地处理、选择和复核阶段。
  7. 引用公共模型能力配置。
  8. 写业务修改到失效范围的映射。
  9. 写主次产物失败与重试规则。
  10. 绑定实际默认资产和adapter，固定版本发布。

  • 区分同步、生成、合成和保存状态。
