# 因赛AI v1.0.4（内测准备）

本版本升级到基于官方 `dsh-v0.2.1-alpha.1` 的因赛 Core，修复 macOS 窗口主题闪烁和提示词增强失败。沿用 Shell + Core + Plugin 架构以及因赛账号、模型网关和内置技能入口。

## 主要变化

- 采用新版设置、输入区和技能接口；保留因赛品牌、完整窗口、账号分区与 12 个内置技能。
- 企业模型网关使用 Core 公开的 PiAiAdapter，继续通过 Chat Completions 请求，保留因赛凭证桥接和图片输入。
- 修复主窗口、关于和更新窗口之间的原生主题反馈循环，避免阴影及主题持续闪烁。
- 提示词增强升级为固定上游 `0.2.7`，使用公开默认模型服务；受管理的 `0.1.9` / `0.2.1` 自动升级，保留用户卸载和自行选择的其他版本。

## 数据兼容与发布限制

新 Core 写入 Session v4，上一正式版 v1.0.3 的 Core 写入 Session v3，并拒绝读取更高代会话。旧会话文件保留不代表旧程序能读取升级后的会话。桌面整体数据兼容声明因此调整为 `writesDataSchema=2`、`readsDataSchema=1..2`；Profile 和账号存储的独立 Schema 仍为 1。

2026-10-08 已验证公网签名：Stable 及三个 Candidate 指针均为 v1.0.3，其三个目标声明只能读取整体数据 Schema 1。现有发布器和客户端都会拒绝向该恢复基线投放 Schema 2 Candidate。不得沿用虚假的 Schema 1 声明、扩大旧版读取范围或绕过门禁。

操作者已选择本轮先交付隔离内测包：沿用 `com.insight-aigc.desktop.dev`、产品名「因赛AI Dev」和独立 userData，关闭生产自动更新。新构建入口 `.github/workflows/internal-release.yml` 只读取固定 CI Runtime artifacts 并输出三平台未签名内测安装包，不生成桌面发布 tag，不公开 Release，不访问 OSS。

本版本仍处于准备阶段。三平台 Runtime 与隔离安装包构建、正式数据迁移与恢复路线、Memory Evolve 的模型配置/同步业务兼容验收尚需收口；未投放 Candidate，未更新 Stable。当前 Dev 包初步人工验收通过，不等同于三平台签名安装与自动升级验收。

## 已有验证

- 功能修复基线的 Shell 127 个文件、918 项测试、类型检查和构建通过；本次内测发布准备加入 Runtime 来源校验后，128 个文件、921 项测试及类型检查通过。
- 提示词增强预览、应用、撤销、失败保留原文、重试和取消通过；真实旧 Profile 的 0.2.1 → 0.2.7 迁移通过。
- macOS 浅色、深色和跟随系统的主题稳定性回归通过；用户已对修复后的 Dev 包完成初步验收，暂未发现明显问题。
- 自动化登录和模型响应使用测试替身；真实企业服务、历史生产会话迁移和其他平台仍以相应人工记录为准。
