# 因赛AI v1.0.0-rc.21 Windows 验证包

rc.21 仅用于 Windows 登录页细节回归，不替换或推广 rc.20 legacy Candidate 指针。

## 本次变更

- 未登录时固定使用深色 Windows 标题栏控件，使最小化、最大化和关闭按钮与深色登录页协调。
- 登录成功后继续跟随系统明暗主题，不改变工作区现有行为。
- 登录页禁止原生右键菜单，避免“全选”造成整页文本选中；登录后的工作区右键菜单保持可用。

## 构建与验收

- 仅触发 `release.yml` 的 `windows-x64` 目标。
- 产物为 Actions artifact，不创建 GitHub Release、不修改 OSS/CDN 文件或更新指针。
- 安装包名为 `insight-1.0.0-rc.21-windows-x64-setup.exe`，未做 Windows Authenticode 签名。
- 手动覆盖安装后，分别在 Windows 浅色和深色系统主题下验证登录页标题栏；登录页右键不应出现菜单，登录成功后右键能力应保持正常。

本文件描述定向验证范围；Windows 实机验收通过前，不将这些改动纳入正式版发布。
