# 因赛AI v1.0.0-rc.18 桥接候选版

`v1.0.0-rc.18` 是现有 v1 Candidate 更新链路的最后一个桥接版本，用于把已经验证的 `v1.0.0-rc.17` 客户端安全迁移到 Desktop Update v2。

## 用户可见变化

- 保留 `rc.17` 已验证的安装、升级与多平台兼容能力。
- 新增“内测更新”显式开关与手动检查入口；Candidate 不在后台检查，也不显示全局更新角标。
- 支持签名的 v2 Candidate 与 Stable 更新索引，并在升级失败时提供经过验证的正式版完整安装包。
- 从 `rc.18` 首次启动时迁移现有 Candidate 用户偏好；用户之后的显式选择不会被覆盖。

## 发布约束

- 继续使用既有 v1 `release.yml` 与 `publish-update.yml` 完成三平台桥接构建、暂存和推广。
- `desktop/candidate/current.json` 指向通过三平台验收的 `rc.18` 后保持冻结。
- 任一平台桥接失败时废弃该版本并发布更高 RC；不得替换 tag、Release 资产或 OSS 对象。
- 本说明随发布代码提交，不代表尚未执行的远端构建、签名、公证、安装或升级验收已经通过。
