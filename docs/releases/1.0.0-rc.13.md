# 因赛AI 1.0.0-rc.13 Windows diagnostic validation

Windows-only workflow artifact; not approved for update-pointer promotion.

- Installer logs now seek to EOF before writing, preserving previous stages.
- A failed/cancelled legacy atomic uninstall no longer triggers a destructive
  regular-uninstall fallback.
- Includes the existing bundled SchemaVersion 2 diagnostic collector.
- Core Runtime and application features remain based on the rc12 baseline.

This is NOT the completed long-path fix. Actual NSIS boundary reproduction,
path-safe handling, rc7 automatic upgrade, and recovery from an already partially
removed installation still require validation. A successful build alone does not
approve installation on the preserved failure machine or establish upgrade safety.

Build with release.yml workflow_dispatch, candidate_tag=v1.0.0-rc.13 and
target=windows-x64. Download the windows-x64 Actions artifact. Do not push a
release tag, run OSS publication, or move update pointers for this validation.
