# 因赛AI 1.0.0-rc.11 Candidate

## Included

- Default model `deepseek-flash`, current display name and legacy alias compatibility.
- Gateway inherits locked official model capabilities; removes local token-budget overrides and preserves recoverable error states and official compaction behavior.
- Insight home logo and slogan, removed preview badge and old login/startup slogan.
- Native sidebar replaces managed better-sidebar; Windows window/taskbar title is 因赛 AI.
- Preserved login, account isolation and API-key interception integration.
- Persistent Windows installer/uninstaller diagnostics and bundled read-only collection script.
- Runtime `insight-runtime-v0.1.5-rc.2-insight.1`, Core commit `42ddfb640a97d551e458613d11ddb73936d15e11`, locked for all three platforms.
- Release preflight accepts the published Insight Runtime revision suffix.

## Validation and remaining gates

Shell tests and type checks run before dispatch. Build targets: macOS arm64, macOS x64, Windows x64. CI produces a verified draft Candidate release; OSS pointer promotion remains a separate step.

Real Windows rc8/rc10 → rc11 upgrade remains a required acceptance check. Added logs do not establish that the existing failure is fixed. Old uninstallers cannot gain internal logging retrospectively. On failure preserve `%TEMP%\insight-desktop-update-logs`.

Native sidebar does not reproduce better-sidebar's extra editor, terminal, Git and browser panels. Enterprise Gateway service capacity, real-service account acceptance and Windows title display still need real-device verification.

`scripts/clean-windows-install.ps1` is an explicitly invoked maintenance utility, defaults to report-only, and is not bundled or called by the updater. Do not run it before collecting failure evidence.
