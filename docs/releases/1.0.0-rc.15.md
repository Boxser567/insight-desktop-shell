# 因赛AI 1.0.0-rc.15 全平台候选版

RC15 是基于最新 `origin/main` 收口的全平台 Candidate，统一包含此前分支中已验收的业务能力、客户端修复和 Windows 升级加固。本版本计划使用同一提交构建 macOS ARM64、macOS x64 与 Windows x64，不复用 RC14 的 Windows-only 制品。

## 主要能力

- Core Runtime 固定为 `insight-runtime-v0.1.6-alpha.2-insight.1`，三平台共同使用 Core commit `fbbcc26c251a800929cd5414a23940974ad3453b`，企业 Gateway 继续使用 Chat Completions 协议。
- 集成企业客户端联网搜索、鉴权 Skill 请求转发、专家技能多选，以及面向用户的中文技能名称、描述、搜索别名和工作区文件 remote 注入。
- 预装 Profile 不再携带 Harness 已自带的 `dsh-genui` 和 `dsh-market`；保留并验证 `dsh-memory-evolve@0.1.0`，升级 `dsh-prompt-enhance` 至 `0.2.1`。
- 本地 DEV 固定使用测试业务服务；Candidate 和 Stable 安装包固定使用生产用户中心、模型 Gateway、Skill Proxy 与业务 API。
- 关于窗口、更新窗口、Windows 原生标题栏按钮区域和提示词增强插件支持浅色、深色及跟随系统的实时主题切换；关于窗口文案调整为 `Powered by InClaw`。
- 更新下载完成后直接进入安装并重启流程，不再要求用户额外点击“安装并重启”。

## 修复与兼容

- 修复沙箱 update preload 引用共享 CJS chunk 后无法加载、导致更新窗口空白的问题。
- 修复主题切换后 macOS 原生标题栏、Windows `titleBarOverlay` 和已打开辅助窗口不同步的问题。
- 保留 RC14 已验证的 Windows 旧版本兼容卸载器、长路径原子迁移、失败回滚、进程树清理和持久诊断日志能力。
- 保留 macOS Safe Storage 正式身份、生产更新源、同源完整安装包兜底与 Candidate/Stable 双阶段发布门禁。

## 构建与验收门禁

- 发布版本：`1.0.0-rc.15`
- Candidate tag：`v1.0.0-rc.15`
- 构建范围：`all`
- 服务环境：`production`
- 平台：`darwin-arm64`、`darwin-x64`、`win32-x64`

远程构建前必须通过完整 TypeScript 检查、桌面集成类型检查、Vitest、普通生产构建、Runtime 锁校验、插件独立安装/启动验证和发布 preflight。Draft 生成后先 stage 到 OSS 并核对签名清单与 CDN 字节，再执行三平台干净安装、覆盖安装、主题切换、Skill、搜索、插件、更新和 Windows 旧版本升级验收。任一平台失败时停止推广并递增 RC，不覆盖已公开 RC15 资产。
