# 因赛AI v1.0.0-rc.19 桥接候选

rc.19 是 rc.17 到 Desktop Update v2 的最终 legacy Candidate 桥接候选。rc.18 已因生产包中
沙箱 About preload 引用拆分模块而废弃；不得覆盖 rc.18 的 tag、Release 或不可变资产。

## 本次修复

- About preload 改为单文件沙箱实现，恢复内测开关、手动检查与主题同步。
- legacy Candidate 首次启动迁移为显式加入内测；后台仍只检查 Stable。
- 恢复基线和 v2 发布器固定接受完成三平台验收的 rc.19。
- 更新链路增加本地指针防回放、签名验收/拒绝记录、Candidate 撤回 tombstone、Stable 指针
  消失保护、元数据与安装包摘要绑定及响应大小限制。

## 发布与验收门禁

- rc.17 的 macOS arm64、macOS x64、Windows x64 必须自动发现、下载、安装 rc.19，并保留
  userData、账号、会话、工作区、设置和插件。
- 已安装 rc.18 的内部测试机不会通过 Stable-only 后台任务发现 legacy rc.19，必须人工安装
  rc.19，并单独记录该路径，不得冒充自动升级证据。
- About 窗口需在明暗主题下验证内测开关、风险确认和“检查内测更新”；Candidate 不得产生
  后台检查、红点或主动通知。
- 三平台验收通过后才允许把 `desktop/candidate/current.json` 永久冻结到 rc.19；失败则消耗
  rc.19 并发布更高 legacy RC，禁止替换任何已发布字节。

本文件描述待发布范围，不代表远端构建、签名、公证、安装或升级验收已经通过。
