# 因赛AI v1.0.1

本版本修复正式版候选中极简模式无法展示内置专家技能的问题，面向 macOS Apple Silicon、macOS Intel 与 Windows x64。

## 主要变化

- 极简模式与标准模式统一加载随客户端交付的内置专家技能。
- 保持内置技能白名单与隐藏规则不变，不扫描或暴露额外的用户技能目录。
- Core Runtime 更新为 `insight-runtime-v0.1.6-alpha.2-insight.4`，三平台统一锁定到 Core commit `5f668026071a5c2f2a0796aff1900be62b0aebe4`。

## 发布门禁

同一批 `v1.0.1` 制品必须先完成三平台构建与 Candidate 验收；验收通过后才能原样转为 Stable，不重新构建。
