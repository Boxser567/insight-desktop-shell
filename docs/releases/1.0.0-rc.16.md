# 因赛AI 1.0.0-rc.16 测试版本

本版本用于平台修复验收，不代表生产推广。RC15 资产和生产更新指针保持不变。安装包沿用正式应用身份，手动安装会覆盖现有因赛AI；打包后的服务环境为生产环境。

## 修复范围

- Core 普通 Windows Job 目标使用 CREATE_NO_WINDOW，受限令牌创建标志不变。需要用实际安装包验证 Windows 10/11 的黑窗口、任务栏及进程稳定性。
- 托管 Profile 迁移到第 8 代，在 Harness 启动前移除已退役的 GenUI/Market 依赖、包和配置引用，失效旧锁文件与安装标记。
- 离线登录页支持重置本地认证状态，并增加不包含凭据的网络诊断。网络根因仍须在受影响设备上确认。
- 保留 Electron 44.0.0，最低 macOS 13；安装包和更新元数据明确系统要求。不恢复 macOS 12 支持。

## 构建与验收

Core 修复提交为 `be346c81694e14091bc4021cac78d3cad5dd6090`，三平台 Runtime 必须统一锁定该提交及各自的 SHA-256，再构建 Shell。不得复用 RC15 Runtime 宣称已修复 Windows 问题。

Windows 原生 CI 已通过 84 项测试；Shell 复核的认证、迁移及更新专项测试通过 92 项。它们不能替代实际安装包验收。

推广前必须完成 Windows 10/11 三种权限模式各连续 20 次 PowerShell、取消及输出检查，旧版缺失插件的覆盖升级，以及 macOS Intel/Apple Silicon 登录与离线重置。验收记录见 [平台修复验证记录](../acceptance/2026-09-21-platform-repair.md)。
