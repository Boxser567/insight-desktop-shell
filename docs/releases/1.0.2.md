# 因赛AI v1.0.2

本版本修复部分 Windows 既有 Profile 的「专家技能」列表仍加载旧版客户端代码的问题，并同步产品技能。

## 主要变化

- 启动时同步刷新 Profile 中已安装的第一方集成插件，确保「专家技能」入口使用当前技能过滤逻辑，不显示电脑上单独安装的技能。
- `bundled-skills/` 与阿里云 Codeup `insight-desktop-skills` 的 `master` 提交 `dcc054102fe735956f755504883afe982b0db3a0` 保持一致；按产品维护的技能列表更新展示名称、增删和 PPT 技能内容。
- Core Runtime 保持 `insight-runtime-v0.1.6-alpha.2-insight.4`，不升级用户数据格式。

## 发布门禁

macOS Apple Silicon、macOS Intel 和 Windows x64 必须从同一 `v1.0.2` 提交构建。三个 Candidate 目标完成安装与升级验收后，原样转为 Stable。
