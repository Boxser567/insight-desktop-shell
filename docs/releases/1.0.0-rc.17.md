# RC17 Windows 验证包

目的：验证上游隐藏控制台与 Node 子进程入口适配，以及补充的 renderer 卡死/退出诊断。

- 基线：已发布 RC16，加 codex/upstream-audit-20260921 定向适配。
- 保持 Electron 44.0.0、Core 0.1.6-alpha.2 / insight.2；无需重建 Runtime。
- 仅触发 release.yml 的 windows-x64 目标，产物为 Actions artifact，不创建正式发布，不修改 OSS 更新指针。
- 包名：insight-1.0.0-rc.17-windows-x64-setup.exe。沿用正式应用身份，手动安装覆盖当前客户端并使用原有用户数据。安装包未做 Windows Authenticode 签名。
- 仍使用生产服务，不将编译包指向测试后端。

## 手动验收

1. 不清理 RC16 数据，正常退出客户端后安装 RC17，确认关于窗口版本。
2. 在无敏感内容的新会话中，分别选择工作区修改、完全权限，输入文本（包括中文输入法），确认可输入、发送且不闪退。
3. 连续执行多次 pwsh 命令，观察任务栏是否反复出现新窗口、输入焦点是否被抢；同时验证取消运行、退出客户端。
4. 查看 Harness 日志，确认出现 hidden console 状态和 Node child-process windowsHide default enabled。unavailable 表示原生控制台处理未成功，不应当作通过。
5. 记录 Windows 版本、默认终端宿主、实际测试结果；若异常，记录时间并保存日志和 Windows Application Error/Hang/WER 事件。

当前输入闪退无法复现，不将本批修改视为已证明解决。CI 测试通过也不能代替 Windows 桌面视觉/焦点验收；不得据此自动推广 RC17。
