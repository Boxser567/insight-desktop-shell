# 登录页 Dot Grid 视觉升级设计

## 目标

在不改变短信、密码、验证码、协议勾选和错误提示逻辑的前提下，将登录页升级为统一的深色 AI 工作台视觉。保留“因赛AI”“以专业为引擎”“让团队与 AI 共成长”和“欢迎登录”等现有文案。

## 已批准方向

- 使用方案 C：石墨靛蓝默认点、因赛主蓝 hover 核心、克制的靛紫色外圈和回弹余辉。
- 使用全屏 Dot Grid，不再使用传统左右双色分栏或有边框登录卡片。
- 登录表单继续位于右侧，控制在约 420px，并通过局部石墨到靛蓝的柔和遮罩保证可读性；遮罩没有可见边框，输入框边界保持克制。
- 品牌位于左上，双行品牌口号位于左下；从客户端最小尺寸 `800×480` 起始始终保留双栏结构与完整文案。

## 动效与性能

交互参考 React Bits Dot Grid，但不引入 GSAP 或整套组件库。Canvas 组件在本地实现，固定使用 `dotSize=2`、`shockRadius=190`、`proximity=150`、`returnDuration=1.3`。鼠标接近时点阵从默认石墨靛蓝过渡为靛紫色，再在核心处过渡为 `#315dfb`，同时放大并产生轻微径向形变；离开后在 1.3 秒内回弹。动效只由 hover 驱动，不绑定点击事件。

Canvas 将设备像素比限制在 2，使用 `ResizeObserver` 响应窗口变化，并在页面不可见或动画稳定后停止逐帧绘制。`prefers-reduced-motion` 下保留静态点阵和 hover 色彩反馈，但关闭位移动效。

## 响应式与兼容性

页面从客户端规定的最小尺寸 `800×480` 起始，始终维持品牌区与表单区的双栏桌面结构，不增加移动端单列分支。低高度下表单区域允许纵向滚动。实现只依赖 React 18、Canvas 2D 和当前 Electron/Chromium 已支持的浏览器 API。

## 验收标准

- 登录业务逻辑和可访问性属性不变。
- 默认点、hover 核心、回弹余辉和登录区遮罩与批准的方案 C 一致。
- 窗口缩放、高 DPI、窄宽度和低高度均不出现裁切或模糊点阵。
- TypeScript 类型检查、现有测试和 renderer 构建通过。
